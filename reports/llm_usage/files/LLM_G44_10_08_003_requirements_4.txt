7. Classification Metrics Design
Precision
Formula
TP / (TP + FP)

Meaning

Positive prediction reliability.

Recall
Formula
TP / (TP + FN)

Meaning

Detection capability.

F1
Formula
2PR / (P + R)

Meaning

Balance between precision and recall.

Accuracy
Formula
Correct predictions / Total predictions

ROC-AUC
Meaning

Ranking ability of classifier.

Edge Case

Single-class evaluation set.

ROC-AUC undefined.

Must:

raise controlled warning
store null value
Confusion Matrix

Layout:

[[TN FP]
 [FN TP]]

Common Mistakes
Swapping labels
Wrong positive class
Computing ROC-AUC from labels instead of probabilities
Failing on imbalanced classes

Recommended structure:

  "classifier": "...",
  "seed": 42,

  "n_features": 0,
  "target_distribution": {},

  "class_1": {

  },

}

integer >= 0
