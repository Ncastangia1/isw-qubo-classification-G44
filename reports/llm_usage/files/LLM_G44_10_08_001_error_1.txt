# SCORE GENERATION STRATEGY

All supported classifiers provide:

```python
predict_proba(...)
```

Generate score as:

```python
predict_proba(X)[:, 1]
```

Meaning:

```text
Probability of positive class (class = 1)
```

Requirements:

```text
0 <= score <= 1
```

DO NOT:

- use decision_function
- use predicted labels as scores
