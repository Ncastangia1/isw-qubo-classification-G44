"Technical Design Document – preprocessing.py
Purpose

preprocessing.py is the first executable stage of the project pipeline.

Its outputs become the direct inputs of the QUBO feature-selection subsystem. Therefore this module must guarantee:

dataset integrity
deterministic preprocessing
reproducible normalization
consistent feature removal
specification-compliant outputs

Because all subsequent stages depend on its output, preprocessing errors propagate through the entire pipeline.

SECTION 3 – Feature Elimination Design
Specification Statement

The specification states:

eliminate features with less than minPercValid non-zero or non-missing values.

Interpretation:

Define:

valid value =
not NaN
AND
not 0


For each feature:

valid_ratio =
valid_count / total_rows


Feature survives if:

valid_ratio >= minPercValid


Feature removed if:

valid_ratio < minPercValid


This is the most literal reading of the requirement.

Case A
Data
95% zeros
5% valid values

Result
valid_ratio = 0.05


If:

minPercValid = 0.05


Feature survives.

Reason:

Condition is not less than threshold.

Case B
Data
94% zeros
6% valid

Result
0.06 > 0.05


Feature survives.

Case C
Data
95% NaN
5% values

Result
valid_ratio = 0.05


Feature survives.

Case D
Data
90% NaN + zeros combined
10% valid values

Result
valid_ratio = 0.10


Feature survives.

Case E
Data

Constant non-zero column.

Example:

5
5
5
5
5

Result

All entries valid.

valid_ratio = 1.0


Feature survives elimination phase.

Important:

Normalization phase must later handle zero variance.

Case F
Data

All ones.

Result

All entries valid.

valid_ratio = 1.0


Feature survives elimination phase.

Ambiguities
Ambiguity 1

Meaning of:

non-zero or non-missing


Possible readings:

NOT zero AND NOT missing
NOT zero OR NOT missing

The first interpretation is more consistent with the examples and project intent.

Ambiguity 2

Constant Columns

Specification does not explicitly say whether constant columns should be removed.

Recommendation:

Keep them in elimination phase.

Handle during normalization.
