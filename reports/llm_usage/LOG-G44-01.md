# FEATURE ELIMINATION RULE

Use the interpretation approved in the TDD.

Define a valid value as:

```text
NOT NaN
AND
NOT 0
```

For every feature:

```text
valid_ratio =
(number of valid values) / (number of rows)
```

Feature survives if:

```text
valid_ratio >= minPercValid
```

Feature is removed if:

```text
valid_ratio < minPercValid
```

Important:

- NaN values do NOT count as valid.
- Zero values do NOT count as valid.
- The threshold comparison is inclusive.

Example:

If:

```python
minPercValid = 0.05
```

and:

```text
valid_ratio = 0.05
```

the feature survives.

Store removed feature names.

Preserve original feature order.

Handle correctly:

## Constant non-zero columns

```text

5
5
5
```

These columns MUST survive feature elimination.

They are NOT removed.

## All-ones columns

Example:

```text
1
1
1
1
```

These columns MUST survive feature elimination.

# NORMALIZATION REQUIREMENTS

Apply z-score normalization:

```text
z = (x - mean) / std
```

Only feature columns are normalized.

Target column is excluded.

Use vectorized implementation.

# ZERO STANDARD DEVIATION RULE

For any feature where:

```text
std == 0
```

DO NOT:

- remove the feature
- generate NaN
- generate Â±inf

Instead:

Convert the entire normalized feature column to:

```text
0
```

Log a warning.

This behavior is mandatory.
