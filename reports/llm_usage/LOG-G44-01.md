# FEATURE ELIMINATION RULE

Use the interpretation approved in the TDD.

Define a valid value as:

```text
NOT NaN
AND
NOT 0
```

For every feature:

```text
valid_ratio =
(number of valid values) / (number of rows)
```

Feature survives if:

```text
valid_ratio >= minPercValid
```

Feature is removed if:

```text
valid_ratio < minPercValid
```

Important:

- NaN values do NOT count as valid.
- Zero values do NOT count as valid.
- The threshold comparison is inclusive.

Example:

If:

```python
minPercValid = 0.05
```

and:

```text
valid_ratio = 0.05
```

the feature survives.

Store removed feature names.

Preserve original feature order.

```text

Use vectorized implementation.
